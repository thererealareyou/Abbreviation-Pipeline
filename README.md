# Автоматический извлекатель доменных аббревиатур (АИДА)

---

Асинхронный высокопроизводительный микросервис для автоматического извлечения, валидации и транслитерации расшифровок
аббревиатур и определений терминов из неструктурированного текста.

Результаты работы пайплайна формируют базу знаний для дообучения эмбеддинговых моделей в RAG-системах и используются для
расширения поисковых запросов (Query Expansion) в концепции Micro-RAG.

---

### Архитектура и технологии

* Backend: Python 3.12+, FastAPI, SQLAlchemy 2.0.

* СУБД: PostgreSQL (драйвер psycopg v3) с поддержкой транзакционных блокировок и оптимизированных массовых операций (
  Bulk Upsert).

* Очередь задач: Асинхронный распределенный воркер ARQ на базе Redis для отказоустойчивой фоновой обработки тяжелых
  документов.

* LLM-движок: Интеграция через llama-cpp. По умолчанию промпты оптимизированы под квантованную модель T-lite-it-1.0 (
  Q4_K_M), что позволяет эффективно запускать инференс на GPU с объемом VRAM до 6 ГБ.

---

### Ключевые особенности

* Многоэтапный конвейер: Процесс разделен на 4 изолированных этапа (поиск, дедупликация, разрешение конфликтов,
  транслитерация). Это минимизирует галлюцинации LLM и гарантирует строгую проверку данных с сохранением промежуточных
  состояний.

* Глобальное разрешение конфликтов: Автоматическое выявление коллизий (когда одна аббревиатура имеет разные определения
  в разных документах) и сборка единого системного словаря (Global Dictionary).

* Гибкая конфигурация: Настройка системных промптов, параметров генерации LLM и лимитов батчей изолирована в
  config/settings.yaml.

* Инженерное логирование: Структурированные JSON-логи для продакшена (ELK/Loki) и кастомное цветовое форматирование для
  локальной консоли Docker.

---

### Запуск

Bash

```
git clone https://github.com/thererealareyou/Abbreviation-Pipeline.git
cd Abbreviation-Pipeline
cp .env.example .env
# Отредактируйте .env с учётом своих настроек
docker-compose up --build
```

После запуска интерфейс управления пайплайном и API-документация доступны по адресу: http://localhost:8000/docs (Swagger
UI).
